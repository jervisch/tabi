# TABi — Illustrated Japan Map Asset Prompt

Create the primary visual map asset for 旅 TABi.

## Goal

A geographically recognizable illustrated map of Japan for a cozy Japanese anime travel journal.

## Style

- hand-drawn Japanese travel illustration
- simple watercolor anime aesthetic
- warm washi paper
- clean ink outlines
- soft blue water
- cream land
- muted moss-green terrain accents
- restrained peach/vermilion accents
- subtle paper grain
- contemporary and elegant
- no characters
- no photorealism

## Geography

Japan must be recognizable and proportionally correct:
- Hokkaido
- Honshu
- Shikoku
- Kyushu
- Okinawa islands

Include prefecture boundaries, but keep them visually subtle.

Do not invent geography.

## Composition

Leave enough negative space for UI overlays.

Avoid embedding permanent city names into the artwork unless specifically required. Geographic labels should preferably be rendered by the app so they remain localized and interactive.

Include subtle environmental motifs:
- clouds
- stylized waves
- distant mountains

Do not add excessive decoration.

## Output

Prefer a clean layered/vector-friendly source if possible:
- base map
- water
- land
- prefecture boundaries
- decorative motifs

If rasterized, create a high-resolution source suitable for iPhone rendering.

The coding agent should use this only as the visual layer; geographic hit-testing remains data-driven.
