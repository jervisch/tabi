# TABi — Visual QA Prompt

Review the implementation against `/design/DESIGN.md` and the reference board.

Check:

## Visual

- Does the app feel Japanese without relying on clichés?
- Does it feel like a cozy illustrated travel journal?
- Is the palette consistent?
- Is typography editorial?
- Are Japanese and English labels balanced?
- Is the map visually distinctive?
- Does the UI avoid default iOS styling?
- Is there enough whitespace?
- Are illustrations restrained?

## Product

- Can a user capture a memory in a few seconds?
- Does the captured photo automatically acquire location context?
- Does the Atlas visibly change after a new memory?
- Can the user drill Japan → prefecture → city → place?
- Is outside-Japan state understandable?

## Anti-patterns

Flag:
- default MapKit map
- default iOS tab bar
- generic rounded cards everywhere
- excessive shadows
- excessive gradients
- random emojis
- too much red
- too many decorative Japanese symbols
- feature creep
- unnecessary onboarding

## Final question

If all logos and text were removed, would the visual language still look like the same product?
