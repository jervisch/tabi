# TABi V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship V1 — capture → location → memory → atlas — as a coherent Japanese photographic atlas app (iOS-only).

**Architecture:** Single-target SwiftUI app, folder modules, Foundation-only Domain. Memory + Visit in SwiftData; geography as bundled prefecture polygons + city points; derived hierarchy (no nested place tables). Deterministic visit heuristics; composable CoreImage film pipeline.

**Tech Stack:** Swift 6, SwiftUI, MapKit, CoreLocation, AVFoundation, Photos (add-only export), CoreImage, SwiftData. iOS 17.0 minimum. No third-party dependencies. Project generated by XcodeGen (`project.yml`).

## Global Constraints

- Platform: **iOS 17+**, iPhone first, **Japan-only** map/atlas
- No third-party packages without explicit user approval
- No: accounts, social, itineraries, weather, booking, recommendations, AI captions, world map, Android, cloud sync
- Domain/ must not import SwiftUI or UIKit
- Design tokens: Washi `#F5F1E8`, Sumi `#252525`, Moss `#68705A`, Indigo `#26384A`, Vermilion `#C95745` (sparingly)
- English label primary, Japanese secondary on camera place label
- Atlas stats: `N / 47 prefectures · M cities`
- Outside Japan: human figure + “Exploring somewhere else in the world”
- 旅/TABI branding: splash/loading only
- After capture: polaroid-style confirm card
- Memories: Year → Trip; filters by location and time
- Photos: app sandbox primary; optional export to system Photos
- V1 location: foreground + photo-time only
- Map geometry: prefecture polygons + city points
- Core loop only: Capture → Remember → Atlas
