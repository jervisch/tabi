# TABi bundled fonts

The Noto CJK files are extracted JP faces from the system Noto CJK collections and are intended for use under the SIL Open Font License 1.1. Noto CJK is published by the Noto project; see the official repository and license.

EB Garamond files are from the installed EB Garamond distribution and are licensed under the SIL Open Font License 1.1.

Official references:
- Noto CJK: https://github.com/notofonts/noto-cjk
- Google Fonts Noto metadata: https://github.com/google/fonts/tree/main/ofl
- EB Garamond Google Fonts metadata: https://github.com/google/fonts/tree/main/ofl/ebgaramond

The app should ship the corresponding OFL license notice with redistributed font files.
