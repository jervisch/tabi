## Japan geography data

- File: `japan_prefectures.geojson`
- Source: [dataofjapan/land](https://github.com/dataofjapan/land) (prefecture boundaries derived from open Japanese government geospatial data)
- License: see upstream repository; intended for open use of prefecture boundaries
- Processing: polygons simplified for app bundle size; properties mapped to `id`, `nameEn`, `nameJa`
